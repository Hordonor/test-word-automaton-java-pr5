# Автомат пошуку TEST — практична робота 5

Java 17 Maven-проєкт реалізує детермінований скінченний автомат, який шукає точне входження підрядка `TEST` у довільному рядку. Повертається стан `F`, якщо слово знайдено; інакше повертається найдовший відповідний префіксний стан `S`, `1`, `2` або `3`.

## Запуск

Двічі натисніть `run.bat`: він перемикає консоль на UTF-8, запускає параметризовані тести, після успішної збірки просить ввести рядок і наприкінці чекає на клавішу перед закриттям вікна.

У PowerShell можна виконати:

```powershell
chcp 65001
./mvnw.cmd clean test
./mvnw.cmd exec:java
```

## Переходи

| Стан | Вхід | Наступний стан |
|---|---|---|
| `S` | `T` | `1` |
| `S` | інший символ | `S` |
| `1` | `E` | `2` |
| `1` | `T` | `1` |
| `1` | інший символ | `S` |
| `2` | `S` | `3` |
| `2` | `T` | `1` |
| `2` | інший символ | `S` |
| `3` | `T` | `F` |
| `3` | інший символ | `S` |
| `F` | будь-який символ | `F` |

Переходи `1 → 1` на `T` і `2 → 1` на `T` зберігають перекриті префікси. Без них наївна схема помилково пропустить `TEST` у рядках `TTEST` і `TETEST`.

Параметризовані JUnit-тести перевіряють усі переходи, часткові збіги, порожній рядок, відсутність збігу, збереження фінального стану та випадки перекривання.
